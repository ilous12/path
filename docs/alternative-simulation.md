# AIIR 이벤트 실험 시뮬레이션

## 사용자 흐름
- 이벤트 페이지의 `실험` 또는 타임라인 AIIR 이벤트 하단의 `실험 추가·관리`에서 등록합니다.
- 상세 분석에서 선택한 실험의 제목·근거를 가져올 수 있습니다. 기존 상세 분석 모델의 수치 가정은 별도로 확인합니다.
- 가격 조정·혜택 변경·채널/마케팅·운영 개선·비정형 유형 및 사용자 정의 신규 유형을 지원합니다.
- 초안을 적용하면 AIIR 이벤트 아래 실험 표시와 매출·순익 점선 예측이 나타납니다. 여러 실험은 독립적으로 비교하며 효과를 합산하지 않습니다.
- 적용 해제로 예측을 숨기고, 복제·수정으로 새 버전을 등록합니다. 원본 연결과 상태 변경 이력을 보존합니다.
- 적용일이 조회 기간에 포함되거나, 마지막 관측일을 조회하는 경우 예정된 실험까지 표시합니다. 예측 종료일까지 차트만 확장하며 미래 실적을 생성하지 않습니다.

## 계산 및 한계
기준은 적용일 전 최대 7일의 데모 매출·비용 평균입니다. 미래 적용일의 기준은 마지막 관측일까지의 최대 7일입니다.

- 매출 = 기준 매출 × (1 + 가격 변화율) × (1 + 수요 변화율)
- 비용 = 기준 비용 × (1 + 수요 변화율) × (1 + 단위 원가 변화율) + 추가 일비용 + 첫날 일회성 비용
- 순익 = 매출 - 비용. 음수 순익을 그대로 표시합니다.
- 일별 계산 후 월간·연간 합산하며 경계 구간은 부분 합계입니다.
- 모든 비용을 수요 연동 비용으로 단순화합니다. 통계 예측이나 검증된 인과관계가 아닙니다.
- AI 빌드업은 규칙 기반 가정 작성 데모이며 실제 LLM 호출은 없습니다.
- 적용은 로컬 시뮬레이션 반영입니다. 실제 요금제·정책을 변경하지 않습니다.
- 저장은 브라우저 localStorage(`mars-policy-alternatives-v1`)이며 서버/사용자 간 공유는 지원하지 않습니다.
- 숨김 이벤트의 실험은 타임라인 분석에서 제외합니다.

## 검증
`node scripts/check-alternatives.cjs`: 입력 유효성, 과거 기준선, 비용·음수 순익, 독립 시나리오, 미래 실적 미생성, 일·월·연 합산 일치.
기존 데이터 회귀 검사: `node scripts/check-market-data.cjs`.
타입 및 배포 빌드: `pnpm typecheck`, `pnpm build`.

## 타임라인 중심 개편
이벤트는 클릭 팝오버로 내용을 표시합니다. 타임라인 상단에서 이벤트와 실험을 등록합니다. 하단 실험 목록과 비지니스 인사이트는 제거했습니다.
적용 시작일·적용 일수·예측 일수를 분리하며, 과거 날짜도 허용합니다. 적용 종료 후 효과는 즉시 0으로 돌아오는 단순 가정입니다. 이전 저장값은 적용 일수=예측 일수, 해지 변화율=0으로 해석합니다.
색상으로 채운 숫자 마커를 클릭하면 연결 실험을 미리보기하고 강조합니다. 재클릭하면 적용 중인 실험 전체 보기로 돌아갑니다. 회선·해지·매출·순익 점선과 무변경 기준 대비 증감 표를 제공합니다. 반투명 회선·해지 막대는 기준 예상값과 실험 예상값 사이의 기여분이며 실제 관측값을 변경하지 않습니다.

## 선택 실험의 연속 차트
실험 클릭 시 시작·종료일과 적용 구간 음영을 표시합니다. 기존 회선·해지 막대의 두 계열을 유지하면서 실험 시작 이후에는 예측값과 사선 채움을 사용합니다. 별도의 얇은 기여분 막대는 제거했습니다. 매출·순익은 시작 전 마지막 관측점을 공유하여 실선에서 점선으로 이어집니다. 선택 해제 시 기존 관측 차트와 비교 표시로 복원합니다. 원본 데이터는 변경하지 않으며, 예측 기간 밖의 미래 실적은 만들지 않습니다. 월·연 집계는 시작일이 속한 구간부터 전환합니다.

## 현재 타임라인 동작: 강조 전용
실험 클릭은 예측을 표시하지 않고 마커와 적용 구간만 강조합니다. 기본 마커는 노란 배경/검은 글씨, 선택 마커는 검은 배경/노란 글씨입니다. 타임라인은 관측 데이터만 표시하며 실험 예측선·사선 막대·증감표는 노출하지 않습니다. 조회 기간에서 선택 마커가 제외되면 선택을 자동 해제하고, 기간을 되돌려도 자동 재선택하지 않습니다. 실험 등록값과 관리 화면의 계산 기능은 유지합니다. 이 동작이 위의 이전 연속 차트 설명을 대체합니다.

## 간편 실험실
이벤트 연결은 필수가 아닙니다. 프롬프트와 적용 시작일·적용 일수·예측 일수로 독립 실험을 등록합니다. 제목·유형은 프롬프트에서 구성하고 가격 변화율만 명시된 표현에서 추출합니다. 원화 가격 변경의 상대 변화율이나 혜택의 수요·비용 효과는 추정하지 않습니다. 세부 가정은 접힌 선택 항목에서 조정합니다. 연결 없는 실험도 타임라인에 표시되며 클릭 시 강조만 수행합니다. 기존 연결 실험 데이터는 유지합니다.
