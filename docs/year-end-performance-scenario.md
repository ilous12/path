# 2026년 연말 회선 시나리오

입력은 합성 시나리오이며 실제 성과 또는 학습된 예측 결과가 아니다.
공통 실적 기준일은 2026-09-28, 준비된 시나리오는 2026-12-31까지다.
`buildPerformance(range, grain, true)`와 `buildHomePerformance(range, business, true)`로 전체를 조회한다.
기본 호출은 관측 역할의 기준일까지 반환하므로 미래 값이 목표 진척과 모델 학습에 들어가지 않는다.

## 변곡점 명세

아래 수치는 전환일의 일 가입 회선 / 해지 건수다. 이후 날짜에는 작은 주기 변동과 완만한 증가를 적용한다.
시나리오 전환점과 통계적으로 감지한 변곡점 후보는 구별한다. 통계 후보는 기존 직전 7일 평균 대비 20%·30회선 기준으로 계산한다.

## 캠페인 예상선 연결

- 회선 차트에는 회선, 매출 차트에는 매출을 연결한다. 금액을 회선 축에 그리지 않는다.
- 연결점은 캠페인 시작 전일과 마지막 실적일 중 더 이른 날짜의 사업 전체 실적이다.
- 채널 예측값에 `사업 전체 연결점 − 채널 연결점`을 더한다. 비대상 채널은 연결점 수준 유지 가정이다.
- 미래 시작 캠페인은 마지막 실적일부터 시작일까지 수평 점선으로 연결한다.
- 캠페인 예상선은 시작 연결점을 포함하고, 마지막 예상값·증감률·툴팁도 같은 계산 결과를 사용한다.
- 개별 캠페인은 독립 대안이다. 겹치는 캠페인의 효과를 합산하지 않는다.
- 채널 상세의 원래 예측은 변경하지 않는다.
