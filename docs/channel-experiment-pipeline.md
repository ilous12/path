# 기간·채널 분석에서 실험까지

- 전체: `/analysis?workspace=air&start=YYYY-MM-DD&end=YYYY-MM-DD` 정책 실험 섹션.
- 채널: 가입 흐름과 채널 기여의 채널명 또는 상세 링크 → `/analysis?...&channel=APP`.
- 기간별 분석 → AI 실험 3건 제안(규칙형 목업) → 선택 → 위저드 → 요건 분석·확인 → 등록.
- 분석 기간·채널·제안 근거를 `analysisContext`에 저장. 기간 변경 시 제안을 초기화한다.
- `targetChannels`는 이벤트·실험의 선택적 배열. 미지정/빈 배열은 전체 채널. 신규 채널 추가 가능.
- 기존 `channel`은 과거 자료와 호환하도록 보존. 과거 실험의 채널 문자열만으로 자동 범위를 축소하지 않는다.
- 채널 회선·매출·비용·해지는 합성 전체 실적을 일별 최대 잔여 방식으로 배분한다. 채널 순익은 배분 매출−배분 비용. 채널 합계가 전체와 일치한다.
- 채널 실험은 선택 채널들의 직전 최대 7일 실적을 기준으로 계산한다. 실제 채널 원천 데이터·LLM은 미연결이다.
- 신규 미연결 채널은 실적을 생성하지 않는다. 연결된 채널이 전혀 없으면 예측 차트는 연결 대기를 표시한다. 혼합 선택은 연결된 채널만 합산하므로 위저드에 안내한다.
- 세 가지 제안의 조건(예: 순익률 15%)은 데모 기준이다. 포인트 비용·수요 효과·마진 제약은 담당자가 검토해야 한다.

검증: `node scripts/check-alternatives.cjs`, `node scripts/check-market-data.cjs`, 타입 검사·빌드, APP 분석→등록→상세 예상 차트 브라우저 확인.
