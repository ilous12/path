# 스케치 모드

화면 하단 중앙의 스케치 모드 스위치로 전환한다. 기본값은 꺼짐이며 선택은 브라우저에 저장된다.

- 모든 페이지와 포털 메뉴에 공통 적용한다.
- 카드의 비대칭 테두리, 종이 질감, 연필 색상, 제목 밑줄과 차트 선을 사용한다.
- 라이트·다크 테마를 지원한다. 이벤트 구분 색상은 유지한다.
- 데이터·계산·등록·기간 선택은 변경하지 않는다.
- 끄면 `data-sketch` 속성을 제거해 기존 스타일로 복원한다.

구현은 `components/sketch-mode.tsx`, `styles/sketch.css`로 분리한다. 스케치 변경 커밋을 되돌리면 도입 전 화면으로 복구할 수 있다.

검증: 스위치 전환, 라이트·다크 표시, 새로고침 후 유지, 원래 테마·카드 스타일 복원, TypeScript 검사와 프로덕션 빌드.
