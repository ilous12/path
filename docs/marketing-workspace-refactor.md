# 마케터 정책 검토 화면 리팩토링

2026-09-21 적용. 현재 컴포넌트와 사용자 저장 데이터를 유지하면서 정보의 우선순위와 배치를 정리했습니다.

## 평가와 변경

- 차트부터 진입하던 화면을 기간·목표 설정 → 관측 현황 → 시장·실적 타임라인 → 근거 확인 → 정책 검토 → 채널 점검 순서로 재배치했습니다.
- 상단에 선택 기간의 출처 있는 시장 변화, 자사 이벤트, 실험 초안, 전체 관측 이벤트 수를 표시합니다. 서로 포함 관계가 있는 집계이므로 합산 지표가 아닙니다.
- 시장 변화는 출처 있는 이벤트의 최신순 네 건입니다. 중요도 평가나 인과관계 판정으로 해석하지 않도록 표시합니다.
- 정책 검토에는 동일 조건 비교, 비용·영향 분리, 가정·중단 기준 정의를 배치하고 상세 분석 및 실험 관리로 연결합니다.
- 이벤트 목록에서 반복되는 근거 설명은 접기 영역으로 옮겼습니다. 원문과 데이터 구분은 계속 노출합니다.
- 실험은 기존 그룹 관리 기능을 유지하고 카드 간격·경계를 정리했습니다.
- 카드 여백, 제목 계층, 필터 영역, 주요 작업 버튼 위치를 통일했습니다. 상단 통계는 사용 가능한 콘텐츠 폭에 따라 2열 또는 4열로 표시합니다.
- 데이터가 준비된 후에도 기다리게 하던 3초 로딩 연출을 제거했습니다.

## 해석 범위

실적·실험 수치는 기존 합성 데모입니다. 실제 보도와 실적 사이의 인과관계를 추정하지 않습니다. 실제 보도에는 발표·계획이 포함됩니다. 이번 변경은 화면 구조 개선이며 예측 모델이나 실제 정책 자동 적용을 추가하지 않습니다.

## 롤백

변경 직전 작업 파일을 `.rollback/marketing-workspace-20260921/`에 보관했습니다. Git HEAD가 아닌 변경 직전 상태로 복원하므로 이전 작업을 보존합니다.

저장소 루트에서 확인:

```sh
python3 scripts/rollback-marketing-workspace.py
```

실제 복원:

```sh
python3 scripts/rollback-marketing-workspace.py --apply
```

기존 UI 파일 6개를 복원하고 이번에 추가한 `decision-workspace.tsx`를 제거합니다. 복원 도구·문서·백업은 남습니다. 사용자 이벤트, 실험, 그룹, 브라우저 저장소는 변경하지 않습니다. 변경 이후 파일이 수정되었다면 해시 검사가 복원을 중단하므로 이후 작업을 덮어쓰지 않습니다. 그 경우 백업과 현재 파일을 비교해 수동 병합해야 합니다.

복원 후 타입 검사와 빌드를 수행합니다.
