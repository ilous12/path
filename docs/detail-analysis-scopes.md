# 상세 분석 화면 설계

| 진입 대상 | 핵심 질문 | 화면 구성 | 판단·후속 행동 |
|---|---|---|---|
| 조회 기간 | 전체 사업이 어떻게 달라졌나? | 전기 대비 4개 지표, 추이, 시장 변화, 이벤트 근거 | 기존 정책 후보 1·2·3 비교와 시뮬레이션 유지 |
| 자사 이벤트 | 무엇을 실행했고 어떤 변화가 관측됐나? | 선택 이벤트만 표시, 변경 전후, 채널·기간·출처, 최초 발생일 전후 7일 일평균 | 실행·비용 검증 후 채널 대상 실험 후보 검토 |
| 경쟁사·기타 | 우리와 무엇이 다르고 대응할 근거가 있나? | 선택 보도·조건·출처, 동일 상품 비교 기준, 우리 실적의 동시기 변화 | 비교 조건 부족 시 판단 보류, 기간 분석의 정책 검토로 연결 |
| 변곡점 | 언제 흐름이 바뀌었고 지속되는가? | 평가 시점·선택 변곡점, 전후 실적 비교, 원인 가설·추가 검증 | 데모/수동 구분, AI 모델과 신뢰도 미연결 명시 |
| 실험 | 어떤 가정으로 무엇을 검증하나? | 요건·적용/예측 기간·채널·비용·예측 차트·일자별 10행 페이징 | 기존 실험 상세 유지 |
| 채널 | 어느 가입 경로가 기여하고 효율이 어떤가? | 채널 기여율, 신규/번호이동 구성, 4개 실적, 채널 타임라인 | 채널별 3개 실험 제안 → 사용자 선택 → 등록 |

어노테이션은 이벤트 ID 묶음 또는 변곡점 날짜와 수동 이벤트 ID를 전달한다. 상세에서는 실제 카탈로그로 다시 조회하고 숨긴 이벤트를 제외한다. 수동 등록 이벤트도 동일하게 지원한다. 기간·워크스페이스를 링크에 유지한다.

전후 비교는 최초 선택일을 기준으로 전 7일/당일부터 7일의 가용 합성 데이터로 계산한다. 일평균과 실제 관측일 수를 표시하며, 인과효과나 경쟁사 실적으로 해석하지 않는다. 전환율·획득비·유지율은 데이터가 없으면 추정하지 않는다.
