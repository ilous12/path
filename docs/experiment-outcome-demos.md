- 09/14 실험: 287 → 326 → 361 → 389로 크게 증가 후 390 안팎의 웨이브. 관측이 있는 09/21까지 매일 관측 회선수보다 조금 낮게 구성. 09/27까지 예측.

차트 오른쪽 끝 %는 달성률이 아니라 **예측 증감률**입니다. `(표시 구간 마지막 예측값 / 실험 시작 직전 관측값 - 1) × 100`. 조회 기간이 09/21에 끝나면 그날의 점 오른쪽에 회선·해지 각각 표시합니다. 회선 기준 09/07 실험 +20%, 09/14 실험 +60% (반올림). 조회 종료일을 바꾸면 해당 표시일의 값으로 다시 계산합니다. 기준값이 0이면 산출 불가로 표시합니다.

팝업·상세의 관측 대비 평가 수치는 별도의 증가분 달성률이며, 차트 끝점의 예측 증감률과 구분합니다. 모든 실적·예측은 합성·사후 구성 데모이며 인과효과를 뜻하지 않습니다. 실제 역할의 기존 관측 데이터는 변경하지 않았습니다.

과거 데모의 내부 ID는 저장값 연결을 위해 유지합니다. 수정하지 않은 이전 버전만 갱신하고 사용자가 변경한 실험은 보존합니다.
